# Модель предсказания исхода карт CS2

## Описание

Симметричная модель на основе LightGBM с boosting_type='goss' для предсказания победителя конкретной карты в матче CS2.

## Используемые признаки

Все признаки симметричные (delta = team1 - team2):

### Базовые
- `delta_rating` – разница рейтингов из top_teams.txt
- `form_diff_10` – разница взвешенного winrate за последние 10 карт
- `sos_form_diff_10` – разница формы с учётом силы соперников
- `days_since_last_match_diff` – разница дней с последнего матча
- `recent_matches_count_diff` – разница количества матчей за последние 14 дней

### Карточные
- `map_strength_diff` – разница winrate на этой карте за 12 месяцев
- `map_recent_form_diff` – разница winrate на этой карте за 3 месяца
- `map_t_side_winrate_diff` – разница T-side winrate на карте
- `map_ct_side_winrate_diff` – разница CT-side winrate на карте
- `map_sample_diff` – логарифмическая разница количества сыгранных карт

### Взаимодействия
- `rating_x_map_strength` = delta_rating * map_strength_diff
- `form_x_map_form` = form_diff_10 * map_recent_form_diff
- `rating_x_sos` = delta_rating * sos_form_diff_10

### Предсказание для конкретного матча

```python
from predict import predict_match, load_model

model = load_model()

# Модель автоматически находит команды в базе (регистронезависимо)
result = predict_match(
    model,
    team1='Vitality',
    team2='Furia',  # или 'FURIA' - модель найдёт правильный вариант
    map_name='Inferno',
    is_lan=1
)

print(f"Вероятность победы {team1}: {result['prob_team1']:.2%}")
print(f"Вероятность победы {team2}: {result['prob_team2']:.2%}")
```

**Важно:** Модель автоматически ищет команды в базе данных с учётом разных вариантов написания (например, 'Furia' → 'FURIA'). Если команда не найдена, её признаки будут нулевыми, что может привести к некорректным предсказаниям.

## Примечания

1. **Нормализация имён команд**: Все названия команд автоматически приводятся к lowercase и применяется маппинг известных вариаций:
   - `NAVI`, `Natus Vincere` → `natus vincere`
   - `Furia`, `FURIA` → `furia`
   - `FaZe` → `faze`
   - и т.д.

2. Модель симметрична: при перестановке команд местами предсказание инвертируется (P(team1, team2) ≈ 1 - P(team2, team1))

3. Для команд, отсутствующих в top_teams.txt, используется рейтинг 0

4. Все скользящие признаки используют ступенчатые веса по давности матча

5. H2H признаки не используются из-за малого количества встреч между командами
