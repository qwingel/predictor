# Match Outcome Predictor

Система машинного обучения для предсказания результатов киберспортивных матчей на основе рейтинга команд, истории личных встреч и контекста матча.

## 🎯 Основные результаты

- **Точность модели:** 62.27%
- **Алгоритм:** Logistic Regression (C=0.5)
- **Улучшение над baseline:** +2.06%
- **Baseline (простое правило):** 60.21%

### Важное открытие

В ходе анализа было обнаружено, что **простое правило дает 60.21% точности**, а ML модель улучшает результат всего на **2.06%**. Это означает, что:
- `delta_rating` является чрезвычайно сильным предиктором
- Дополнительные признаки добавляют минимальную ценность
- Задача предсказания исходов матчей объективно сложна (много неожиданных результатов)

## 🔍 Признаки (Features)

| Признак | Описание | Использование |

### 4. Важность признаков

```
delta_rating:      -0.3978  ← Самый сильный предиктор
h2h_shrunk:         0.2986  ← Второй по важности
map_missing_flag:   0.0223
h2h_count:          0.0208
LAN_flag:           0.0195
```

**Интерпретация коэффициентов:**
- Отрицательный коэффициент `delta_rating` означает обратную зависимость
- `delta_rating > 0` → Команда 2 имеет выше рейтинг → Команда 1 сильнее → Команда 1 побеждает (-1)

## 🎲 Точность по диапазонам рейтинга

| Диапазон delta_rating | Точность | Интерпретация |
|----------------------|----------|---------------|
| < -50 | 65.00% | Большое преимущество → легко предсказать |
| -50 до -20 | 55.97% | Умеренное преимущество → много неожиданностей |
| -20 до 0 | 60.00% | Близкий матч → неопределенность |
| 0 до 20 | 57.55% | Близкий матч → неопределенность |
| 20 до 50 | 66.33% | Умеренное преимущество → проще |
| > 50 | 68.97% | Большое преимущество → проще всего |

**Паттерн:** Модель лучше работает при больших различиях в рейтинге (>50 или <-50).

## ⚠️ Ограничения

1. **Минимальное улучшение:** Всего +2.06% над простым правилом
2. **Зависимость от H2H:** Точность падает при отсутствии истории встреч
3. **Умеренные матчи:** Проблемы с рейтинговыми различиями от -50 до +20
4. **Дисбаланс классов:** Смещение в сторону предсказания победы Команды 2
5. **Потолок точности:** 62% означает ~38% ошибок

## 🤔 Простое правило vs ML модель

### Простое правило (60.21%)

```python
def predict_simple(delta_rating):
    return -1 if delta_rating > 0 else 1
```

**Плюсы:**
- Простота (одна строка кода)
- Скорость (нет загрузки модели)
- Интерпретируемость
- Не требует обслуживания

**Минусы:**
- На 2% менее точное

### ML модель (62.27%)

**Плюсы:**
- На 2% точнее
- Использует H2H данные
- Учитывает контекст (LAN, флаги)

**Минусы:**
- Сложность
- Требует обслуживания
- Зависимость от библиотек

### Рекомендация

**Используйте простое правило**, если:
- Важна простота и скорость
- 2% разницы приемлемы
- Нет H2H данных

**Используйте ML модель**, если:
- Каждый процент важен
- Есть H2H данные
- Можете поддерживать pipeline
